# 拖拉机大赛 · 网页版（TractorCard）

民间扑克玩法“拖拉机”的网页版实现，玩法参考经典游戏《拖拉机大赛》。两副牌 108 张，四人结对、抢分升级，
规则对照原版随机帮助文件 `TRACTOR.HLP` 实现。目前为**单机模式**，
玩家坐南家，其余三家由电脑接管；联机模式已在代码中预留接口。

## 运行

纯静态页面，无需构建。用任意静态服务器打开根目录即可（因为使用了 ES Module，
不能直接 `file://` 打开）：

```bash
python3 -m http.server 8080
# 浏览器访问 http://localhost:8080
```

## 已实现的规则

全部取自原版帮助文件，逐条对照实现：

| 规则 | 说明 |
| --- | --- |
| 牌型 | 两副 108 张；5=5 分，10/K=10 分，全场 200 分 |
| 大小顺序 | 大王 > 小王 > 主级牌 > 副级牌 >（主 2 > 副 2）> A K Q J … |
| 拖拉机 | 组内序号相邻的连对；同序号的两对（如两对副 10）不构成拖拉机 |
| 亮牌 | 亮单张定主，自保 / 对家保 / 反主 / 自反 / 反无主（四王） |
| 翻底定主 | 无人亮牌时翻底牌第三张，为王则顺次后翻 |
| 甩牌 | 甩牌不成立时强制只出其中最小的一联 |
| 跟牌 | 有对必出对、有拖拉机必出拖拉机（含拖拉机中的对牌） |
| 毙牌 / 盖毙 | 毙牌须全主且拖拉机、对牌数不少于首攻；按对牌与拖拉机大小盖毙 |
| 抠底 | 单张 ×2、对牌 ×4、拖拉机 ×8、三拖 ×16，其余类推 |
| 升级 | 0 分大光 +3，<40 小光 +2，<80 +1，<120 上台，<160 上台 +1，<200 上台 +2，其余类推 |
| 必打级 | 2（或 2 为常主时的 3）、J、A 必打，跳级中不可跳过 |
| 轮庄 | 先亮者为庄；庄家升级由对家坐庄，闲家上台由庄家下家坐庄 |
| 打无主 | 打过 A 后若允许打无主则必打，赢下无主局即赢得全局 |

上述规则是对照原版随机帮助文件 `TRACTOR.HLP` 逐条核对后实现的；
其中原版给出的四个毙牌算例（主 998872 毙副 AK5544 / 不能毙副 AA5544；
主 977 毙副 544、主 884 盖毙；主 977 毙副 567、主 884 不能盖毙）
与三个甩牌算例（98844 遇 J / QQ / 55）均能逐一复现，可用作规则回归。

原版帮助文件本身的文字属其权利人所有，未收入本仓库；
本项目帮助页（`src/help.js`）的规则说明为本项目重新编写，结构、措辞与示例均与原文不同。

## 选项

与原版“选项”菜单对应：游戏规则（2 为常主、反无主、自反、对家保、打无主）、
游戏难度（低 / 中 / 高）、游戏速度（慢 / 中 / 快）、牌面图案、牌背面图案（5 种）、
音乐、音效。设置与牌局存档保存在浏览器 `localStorage`。

## 操作

| 操作 | 效果 |
| --- | --- |
| 左键单击 | 选取 / 放回一张牌 |
| 左键双击 | 直接打出该张牌 |
| 右键单击 | 选取 / 放回同花色（或主牌）中以左的所有牌 |
| 出牌按钮 | 打出已选取的牌 |
| `F1` / `F2` | 帮助 / 开始新游戏 |

## 代码结构

```
index.html          页面骨架（菜单栏、牌桌、手牌区）
styles.css          样式
assets/cards/       牌面素材（52 张 + 2 种牌背，SVG/PNG）
                    joker-big.svg / joker-small.svg 为本项目补做的大小王
src/cards.js        牌与牌堆
src/rules.js        主牌环境、大小顺序、拖拉机拆解、一墩结算
src/play.js         跟牌合法性、甩牌判定
src/game.js         牌局状态机（发牌 / 亮牌 / 扣底 / 打牌 / 升级结算）
src/ai.js           电脑玩家（三档难度）
src/ui.js           渲染与交互
src/main.js         主控制器与菜单
src/help.js         帮助与版权文本
src/persist.js      设置与存档
src/net/transport.js 联机模式预留接口
test/sim.mjs        无界面对局模拟（规则回归测试）
```

## 关于素材

牌面与牌背素材由项目作者自行制作。原版素材中没有大小王，
`assets/cards/joker-big.svg`、`joker-small.svg` 按同一风格补做。

## 测试

```bash
node test/sim.mjs 120     # 120 整局全 AI 对战，校验规则与 200 分守恒
```

## 联机模式（预留）

`src/net/transport.js` 定义了 `Transport` 接口。单机模式使用 `LocalTransport`
把动作直接回环给本地引擎；接入服务器时实现 `RemoteTransport`，
把 `{ type, seat, cards|option }` 动作收发即可，规则引擎与界面层无需改动。
